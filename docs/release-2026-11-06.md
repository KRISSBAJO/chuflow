# ChuFlow release — 6 November 2026

- Mobile: compressed local artwork, Jost typography, compact shortcuts and a light children’s service desk with Today, Families and Insights.
- Attendance: month/year, dates, weekday, church, service, search and attendance sorting on web and mobile. Sunday averages combine services on recorded Sundays; missing Sundays are excluded.
- Finance: offerings and expenses start pending. A different authorized author/editor must review. Source and ledger commit in one transaction. Edits withdraw approval; pending and rejected amounts do not count in approved balances. Historical offerings without status preserve their prior approved reporting treatment.
- Weekly reports: draft, review, submit, acknowledge and lock; WOFBI records Bible school attendees. Comparisons use acknowledged reports from the previous week, calendar month and calendar year. Missing comparisons stay unavailable.
- District reports: immutable submitted snapshots, coverage and acknowledged totals, selected scoped reviewer, acknowledgement or return, audit history.

Web entry: `/weekly-reports/workspace`. Mobile: More → Reports → Weekly spiritual report.

## Mobile delivery

The monorepo is retained. Expo project: `@logaxp/chuflow`.
`apps/mobile/eas.json` defines an Android APK preview and a production store build.
Run EAS commands from `apps/mobile`:

```
eas build --platform android --profile preview
eas build --platform ios --profile production
```

Apple signing and TestFlight processing are separate from deploying the website.

## Release integration checks

The two `*-release.integration.spec.ts` suites use a dedicated local MongoDB replica on port 27129 and separate QA databases. Set `CHUFLOW_RELEASE_QA=1` to run them. Standard tests skip these suites when that flag is absent. They never connect to production.
